# Social-media content

Read [shared defaults](soul.md) for routing and style.

**Fit the format and audience without manufacturing a different personality for each platform.**

- Let story and reel text complement the visual or spoken content.
- Give posts and descriptions only the context their audience needs.
- Make comments and replies responsive to the conversation, not miniature standalone posts.
- Select bio details for the intended audience; verify personal claims before using them.
- Add hooks, or calls to action only when they serve the requested purpose.

Do not infer a writer's habits from the platform or another person's examples.
