# Propose documentation structure

**Goal:** Make the touched material understandable from its overview, with detail available only
when needed.

## Map concerns

- Start with the big-picture explanation established from the documents and their verified sources.
- Identify each concern, audience, existing owner, and reading need within the authorized material.
- Separate explanation, task instructions, reference details, and historical evidence where their
  purposes differ.
- Keep code reality, accepted future work, and historical outcomes distinguishable.

## Propose the smallest structure

- Show the proposed directories or pages and explain each boundary.
- Reuse existing concern directories; do not invent a repository-wide taxonomy for one touched
  guide.
- Keep a document intact when headings and links solve the problem.
- Put the overview first; link to focused detail with explicit reading triggers.
- Give each concern one owner; use links rather than duplicating facts or procedures.
- Keep plans and evidence in their permitted workspace, separate from maintained product
  documentation.
- Avoid empty scaffolding and directories created only to reduce line counts.

## Request the needed approval

- Name affected source files, proposed destinations, and necessary link or index changes.
- Map each original section's unique information to its proposed destination.
- Explain the reader benefit, verification criteria, and rollback.
- Surface uncertain ownership or conflicting agreements before choosing a destination.
- Reuse approval already granted for this exact scope; otherwise wait before restructuring.

## Check the approved result

- The entry page explains what and why before detailed steps or reference values.
- Each concern's entry page lets readers choose relevant detail without reading everything.
- Every unique fact, example, link, qualification, and safety condition remains accounted for.
- Superseded material is clearly historical; current guidance matches verified implementation and
  agreements.
- No unrelated document or unapproved directory changed.
